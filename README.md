# Night City: Chrome Overload

## Sobre o projeto

**Night City: Chrome Overload** é um RPG de combate por turnos desenvolvido em **Java**, inspirado no universo de *Cyberpunk: Edgerunners*.

O jogador assume o papel de um mercenário que precisa escapar de Night City, enfrentando inimigos, ganhando eurodólares e adquirindo implantes cibernéticos para se tornar mais poderoso.

Entretanto, utilizar implantes também apresenta riscos. Quanto mais chrome equipado, maior poderá ser a chance de desenvolver **ciberpsicose**, que resulta em derrota imediata.

## Mecânicas do jogo

- **Combate por turnos:** enfrentar diferentes inimigos utilizando ataques e habilidades.
- **Sistema de vida:** receber dano, recuperar HP com MaxDoc e morrer quando a vida chegar a zero.
- **Eurodólares:** ganhar dinheiro ao derrotar inimigos.
- **Loja de implantes:** comprar, equipar e remover melhorias cibernéticas.
- **Ciberpsicose:** possibilidade de perder a partida ao ativar habilidades especiais.
- **Implantes:** Braços Gorilla, Pele Subdérmica, Sandevistan, Mantis Blades e Capricorn (Capri).
- **Capri:** implante experimental com 90% de chance de morte na primeira ativação. Sobrevivendo, o jogador obtém controle total de seu poder.
- **Banco de dados:** salvar e recuperar o progresso do jogador utilizando MySQL.

## Tecnologias utilizadas

- **Java:** desenvolvimento do jogo e aplicação de Programação Orientada a Objetos.
- **MySQL:** armazenamento dos dados do jogador.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no IntelliJ IDEA.
3. Configure um JDK compatível.
4. Execute a classe `Main.java`, localizada em `src/`.

A configuração e a integração do MySQL serão documentadas conforme o desenvolvimento.
